# Coyote Wash (summer)

Status: **playable**

A red-rock desert canyon after a summer monsoon storm. For now it drives Meltwater Pass's layout
([`../spring-thaw/README.md`](../spring-thaw/README.md)): the same climb and descent, rock fords, ledges, bogs and four
stations (user decision, 2026-11-17: reuse an existing pattern; a layout of its own can come later).

- **Surfaces:** firm red dirt (`dirt.mu` 0.92), slickrock (`rock.mu` 0.86), short heavy red-clay bogs (`mud.mu` 0.30, `sink` 0.28).
- **Round obstacles:** rusty pipeline sections (`pipe`) and weathered telegraph poles (`pole`, drawn with the `logCrossing` art).
- **Low obstacles:** tumbleweed piles, cactus-skeleton tangles, root mounds, half-buried tyres, sandstone ledges, adobe rubble,
  cracked mud ridges, railroad rails and corrugated iron.
- **Ambience:** crows only; a desert wind bed is a separate audio request.

Art: ChatGPT images (2026-11-17) prepared once into `art/` (trimmed sprites, seamless tiles, the wide strips and the backdrop
mirrored to 3:1, the pipe and pole turned 35° so they run back into the road like the other maps' straight logs). Rock and prop
hulls were traced from the trimmed sprites. The masters were deleted afterwards (user decision), so these entries have no `source`.
