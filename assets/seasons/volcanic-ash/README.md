# Cinder Caldera (summer)

Status: **playable**

A green volcanic island inside an old crater. For now it drives Meltwater Pass's layout
([`../spring-thaw/README.md`](../spring-thaw/README.md)): one long climb and descent, rock fords, ledges, bogs and four
stations (user decision, 2026-11-17: reuse an existing pattern; a layout of its own can come later).

- **Surfaces:** loose cinder (`dirt.mu` 0.82), sharp basalt (`rock.mu` 0.9), black ash bogs (`mud.mu` 0.32, `sink` 0.26).
- **Round obstacles:** rusty insulated steam pipes (`steamPipe`, the `pipe` art) and charred logs (`charredLog`, the
  `logCrossing` art).
- **Low obstacles:** pumice heaps, ropy lava crust, roots over lava, buried tyres, basalt column steps, concrete foundations,
  ploughed cinder ridges, rusty pipe supports and steel sheets.
- **Ambience:** crows only; a wind or steam bed is a separate audio request.

Art: ChatGPT images (2026-11-17) prepared once into `art/` like Coyote Wash's (see `../desert-wash/README.md`). The masters
were deleted afterwards (user decision), so these entries have no `source`.
