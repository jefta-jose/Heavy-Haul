# HUD

SVG icons inlined by the build wherever `src/index.html` has `<!--icon:name-->`. Use a 24×24 view
box with `currentColor` strokes or fills so the CSS can color them.


`fonts/barlow-condensed-600.woff2`, `-700.woff2` and `-700i.woff2` are the display font (Barlow Condensed, SIL Open Font License 1.1, Google Fonts' Latin subset). `tools/build.js` puts it in the page, so it shows offline.
